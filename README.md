# learn-rust

A learning repository: Rust, worked by the practices of scientific work.

- Every learning unit states, before the work, what is to be learned and
  which observable artefact proves it. A goal written after the code fits
  the code.
- Claims about the language are made by runnable examples in this tree,
  not by prose. `cargo test` is the gate.
- Sources are cited by chapter and edition. A claim from memory is marked
  as such until grounded.
- Wrong hypotheses are records, kept, not overwritten. The wrong guesses
  are the most instructive artefacts.

This repository begins with a planning phase. Nothing is built until the
plan has been reviewed by something that did not write it. The plan lives
in this tracker.
